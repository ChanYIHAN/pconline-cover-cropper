# PConline 封面快裁

面向太平洋科技编辑与内容生产场景的纯前端封面裁切工具。无需安装，图片仅在当前浏览器中处理，不会上传到服务器。

## 在线使用

访问：<https://chanyihan.github.io/pconline-cover-cropper/>

## 功能

- 内置首页主焦点、焦点双图、资讯卡片、频道首图、列表小图、视频横图和专题缩略图规格
- 拖拽构图、滚轮缩放、旋转、水平翻转、三分线和安全区
- JPG、WebP、PNG 导出及画质调节
- 设置目标文件大小（KB），自动寻找合适画质，保持目标像素不变
- 多图队列、当前图片全规格 ZIP、全部图片当前规格 ZIP
- 支持 32–8000 像素的自定义尺寸
- 完全离线可用，无第三方脚本和图片上传

## 使用方法

1. 打开在线地址，或直接双击 `index.html`。
2. 拖入、粘贴或选择一张或多张图片。
3. 选择官网规格，在画布中拖动和缩放图片。
4. 选择格式、画质；如网站限制上传体积，可开启“限制大小”并填写 KB。
5. 下载当前裁图，或生成批量 ZIP。

## 技术说明

项目为无依赖的单文件 HTML 应用，使用浏览器 Canvas API 完成裁切与编码，并内置无压缩 ZIP 打包器。所有偏好只保存在浏览器本地。
