# PConline 封面工作台

面向太平洋科技编辑与内容生产场景的纯前端封面裁切工具。无需安装，图片仅在当前浏览器中处理，不会上传到服务器。

## 在线使用

访问：<https://cover.ekhart.cn/>（原 GitHub Pages 链接仍会自动跳转）

## 功能

- 内置首页主焦点、焦点双图、资讯卡片、频道首图、列表小图、视频横图和专题缩略图规格
- 首次上传自动按原图比例完整显示，选择官网规格后才进入裁切，也可随时返回原图模式
- 拖拽构图、滚轮缩放、旋转、水平翻转、三分线和安全区
- 九宫格快速定位、撤销/重做和每张图片按规格独立记忆构图
- JPG、WebP、PNG 导出及画质调节，支持按所选规格以 100%、200%、300% 等比例放大输出
- 根据原图、裁切缩放和导出倍率进行清晰度诊断，并提供 1:1 实际像素检查
- 全部官网规格导出前预检，可逐项检查构图与清晰度状态
- 主体锚点与相近比例/全部规格一键联动，避免逐个版位重复定位主体
- 曝光、对比度、高光、阴影、饱和度、色温、锐化、降噪与暗角等非破坏性调整
- 标题、副标题、角标、渐变和 Logo 图层，并内置科技、快讯、硬件、简洁品牌模板
- 带壳截图工作室：浏览器窗口、桌面应用、手机屏幕与极简卡片四类基础外壳，内置 5 套背景模板
- 场景化展示布局：叠层网页、响应式网页＋手机、双机并列与三机阵列，适合页面提案、文章配图和作品集
- 手机与设备样机直接采用 FrameUp-Free 的原始 SVG/透明 PNG 素材，包含 iPhone 17 Pro Max、iPhone 11、Galaxy S9、MacBook Pro、iPad Pro 与 iMac Pro
- 支持 16:9、4:3、3:2、1:1 成片比例，以及外壳大小、留白、圆角、阴影、倾斜和位置微调
- 高清 PNG 带壳图下载与一键复制到剪贴板，适合文章配图、社媒和作品集展示
- 本地背景模糊与背景移除（适合纯色或边缘较清晰的背景），支持容差、羽化与蒙版反转
- WebGPU 边缘增强放大；不支持 WebGPU 时自动使用 Canvas 高质量插值
- 封面版本复制/对比、审核状态与批量套用调整、图层、构图和状态
- IndexedDB 自动保存，可恢复本机项目，也可导入/导出包含原图的项目 JSON
- 设置目标文件大小（KB），自动寻找合适画质，保持目标像素不变
- 多图队列、当前图片全规格 ZIP、全部图片当前规格 ZIP，并显示生成进度
- 支持 32–8000 像素的自定义尺寸
- 完全离线可用，无第三方脚本和图片上传

第三方样机素材及授权信息见 [`THIRD_PARTY_NOTICES.md`](./THIRD_PARTY_NOTICES.md)。

## 使用方法

1. 打开在线地址，或直接双击 `index.html`。
2. 拖入、粘贴或选择一张或多张图片。
3. 选择官网规格，在画布中拖动、缩放或使用九宫格快速定位。
4. 根据清晰度诊断选择格式、画质和导出倍率；需要时打开“1:1 像素检查”。
5. 下载当前裁图，或先执行“全规格预检”再生成批量 ZIP。
6. 需要展示成片时，点击顶部“带壳出图”，选择基础样机或场景组合、背景和画布比例后下载或复制 PNG。

## 技术说明

项目为无依赖的单文件 HTML 应用，使用浏览器 Canvas API 完成裁切、像素调整与编码，并内置无压缩 ZIP 打包器。支持时会使用 WebGPU 做边缘增强插值，其他设备自动回退到 Canvas。图片、项目与偏好均只保存在浏览器本地。

> WebGPU 增强与 200% / 300% 导出可以改善放大后的边缘观感和像素尺寸，但不能恢复原图中不存在的真实纹理。背景移除采用本地颜色边缘蒙版，复杂发丝、透明物体或杂乱背景建议使用专业抠图工具进一步处理。
